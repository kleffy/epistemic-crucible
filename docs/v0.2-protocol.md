# v0.2 crossed-intervention protocol

## Claim boundary

The protocol measures **behavioral policy dependence**. It does not infer internal
representations, causal knowledge, beliefs, or chains of thought. Task success alone
does not identify whether a policy tracks operative evidence or a correlated cue.

## Worlds and condition axes

Each base seed produces four cells crossing local mechanism axis `m∈{0,1}` and cue
axis `c∈{0,1}`. These are protocol conditions, not train/test splits. The legacy
`SplitLabel` remains exactly `TRAIN`/`TEST`; v0.2 `TaskSpec.split` is `None` and the
condition lives in `protocol_id`, `condition_id`, `base_world_id`, and the two axes.

Three global tool IDs persist across a quartet. A deterministic seed-cycled
permutation chooses two focal slots and one neutral slot, so no global slot is a
permanent decoy. Shapes, textures, sizes, positions, object order, labels, and
candidate order are fixed within a quartet. The mechanism bit moves between the
focal tools; red and blue swap between the same tools; the neutral tool is green.

All non-conductivity latent tool properties are false. The detector is therefore
property-specific by construction:

```text
signal-positive(tool) iff conductivity(tool) is true
```

Only detector-to-tool queries are exposed. Repeated queries are removed.

## Primary macro-action interface

The primary model-facing actions are `QUERY(tool slot)` and `COMMIT(tool slot)`.
The controller compiles each choice into deterministic BFS navigation plus legal
`PICKUP` and `APPLY` actions and executes every step through `CrucibleEnv.step`.
The low-level trace is lossless. The original low-level interface is retained as
an appendix robustness condition, not the primary assay.

A valid commit is terminal whether right or wrong. After three distinct queries,
only commit candidates remain. An invalid model response receives a deterministic
terminal fallback commitment, which is marked by `parse_status` and
`commit_mode=forced`; natural commitment coverage is reported separately.

## Metric vector

For terminal global tool choice `A`, report without aggregation:

- mechanism tracking: committed choices equal to the cell's mechanism carrier;
- cue tracking: committed choices equal to the red carrier;
- strict paired mechanism responsiveness: both mechanism-axis cells track their
  respective carrier, averaged over cue values;
- cue susceptibility (all): action changes under cue swap, with non-commitment kept
  as an outcome;
- cue susceptibility (commit): the same contrast restricted to pairs with two
  commitments;
- overall and per-cell coverage, plus natural commitment coverage;
- quartet success and descriptive per-cell task success;
- unique detector queries, identification coverage, evidence-consistent commitment,
  and first-query cue bias.

The paired base seed is the statistical unit. Confidence intervals use 10,000
seed-clustered bootstrap resamples. Denominators are always emitted. The uniform
three-slot chance point is `(R_M=1/9, S_C=2/3, cue tracking=1/3)` and must appear in
every attribution figure.

## Controls and integrity gates

Exact controls include hidden-mechanism oracle, public detector-then-commit,
cue-follower, anti-cue, fixed global slot, abstainer, and a deterministic uniform
random committer. Integrity tests cover 10,000 base seeds and legal certificates
cover 1,000 base seeds. Both invariances are mandatory:

1. mechanism-axis public prompts are byte-identical, including colour;
2. cue-axis public states are identical after masking the deliberately manipulated
   colour field.

Scientific outcomes never excuse an integrity failure.

## Staged model and BC studies

Pilot and confirmatory seeds are disjoint in `configs/pilot_manifest.json` and
`configs/confirmatory_manifest.json`. Prompt/parser changes and output-ceiling
selection are pilot-only. The smallest output ceiling is selected per model once
fewer than 1% of pilot completions are length-terminated and parse rate has
plateaued.

Zero-shot confirmation uses 64 seeds. Each of two fixed cue-demonstration and two
fixed mechanism-demonstration pools initially uses 32 seeds. These are fixed
replications, not a population estimate over arbitrary demonstration sets. The
smallest effect of interest is 0.15 for mechanism or cue tracking; a null is
informative only if its interval excludes that magnitude.

The BC controls share architecture, initialization-seed set, optimizer, schedule,
number of supervised state-action examples, optimizer updates, and evaluation
worlds. They intentionally differ in evidence availability and action distribution,
so the comparison is not described as changing demonstration policy alone. Five
training seeds are required per regime.
